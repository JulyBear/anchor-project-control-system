# 需求库

每条稳定需求使用唯一 ID，建议格式为 `REQ-001`、`REQ-002`。

每条需求至少包含：

- 标题和目标；
- 来源；
- 当前状态：`proposed`、`approved`、`implemented`、`rejected`、`superseded`；
- 验收方式和通过标准；
- 相关设计、任务和验证证据 ID；
- 约束、假设和重新评估条件。

控制要求：

- 不用聊天记录作为唯一需求来源；
- 需求修改不能静默覆盖旧语义；
- 已确认需求改变时，必须分析对设计、实现和验证的影响；
- 没有验收方式的内容只能算想法，不能算可执行需求。

本仓库不包含具体项目需求。使用时从 `templates/requirement.md` 创建项目自己的需求文件。
